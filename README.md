# Inventory-Demand-Stockout-Risk-Analysis

## 📊 Project Overview

This project analyzes inventory demand, stock levels, supplier performance, and stockout risk to identify potential inventory shortages and revenue loss.

The project combines **Python, SQL, and Power BI** to transform inventory data into actionable business insights for inventory and supply-chain decision making.

## 🎯 Business Problem

Inventory teams need to identify:

* Which products are at high risk of stockout?
* Which categories have the highest inventory risk?
* Which regions contribute the most potential revenue loss?
* Which suppliers have lower reliability or higher risk?
* Where should inventory be replenished first?

## 🗄️ SQL Analysis

SQL queries were developed to analyze:

1. Overall inventory performance
2. Stockout risk distribution
3. High-risk inventory items
4. Category performance
5. Regional performance
6. Supplier performance

The analysis focuses on inventory levels, daily demand, risk scores, inventory value, supplier reliability, and potential revenue loss.

* Demand

* Regional performance
* Supplier performance

Users can use filters to investigate inventory risk across different business dimensions.

## 💡 Key Business Questions

The dashboard helps decision-makers answer:

* Where are the highest stockout risks?
* Which products require immediate attention?
* Which categories generate the highest potential revenue loss?
* Which regions require better inventory planning?
* Which suppliers need closer monitoring?
* Which products are below their reorder point?
